# Farai Kapopo — Portfolio

Personal portfolio website for Farai Kapopo, a Computer Information Systems student at Livingstone College.

## 🌐 Live Site

[View the live site](https://muse.ai/s/portfolio-xbs5xotwpnea7)

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript (vanilla)

## 📁 Structure

- `index.html` — page structure and content
- `styles.css` — all styling
- `script.js` — interactive behavior (copy-email button, résumé download)

## 🚀 Run Locally

Open `index.html` in any browser, or serve it locally:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## 🌍 Deploy with GitHub Pages

1. Push these files to a GitHub repo (e.g. `portfolio`)
2. Go to **Settings → Pages**
3. Under **Source**, select `Deploy from a branch` → `main` → `/ (root)`
4. Save — your site goes live in a minute or two
